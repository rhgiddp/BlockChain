```bash
□ 모든 테스트 통과

  $ cargo clippy
  $ npm run lint

□ 빌드 성공
  $ cargo build --release
  $ npm run build

□ Git 커밋 및 푸시

  $ git commit -m "feat: Production ready"
  $ git push origin main
```

### 2. 환경 변수 준비

`.env.production` 파일 생성:
```env
# 블록체인

BLOCKCHAIN_DIFFICULTY=4
BLOCKCHAIN_MINING_REWARD=50

# 데이터베이스
DB_HOST=your-db-host.rds.amazonaws.com
DB_PORT=5432
DB_NAME=konet_production
DB_USER=konet_admin
DB_PASS=strong_password_here

# Redis
REDIS_HOST=your-redis.cache.amazonaws.com
REDIS_PORT=6379
REDIS_PASS=strong_redis_password

# JWT
JWT_SECRET=super_strong_secret_change_this

# AWS (선택)
AWS_REGION=ap-northeast-2
AWS_ACCESS_KEY_ID=your_key
AWS_SECRET_ACCESS_KEY=your_secret

# 모니터링
SENTRY_DSN=https://your-sentry-dsn
```


## ☁️ AWS 배포

### A. EC2 인스턴스로 배포 (간단)

#### 1. EC2 인스턴스 생성

**AWS 콘솔 → EC2 → 인스턴스 시작**

**추천 사양:**
- **AMI**: Ubuntu 24.04 LTS
- **인스턴스 유형**: t3.medium (개발), t3.xlarge (프로덕션)
- **스토리지**: 100GB SSD
- **보안 그룹**:
  ```
  SSH (22): 내 IP만
  HTTP (80): 0.0.0.0/0
  HTTPS (443): 0.0.0.0/0
  Custom (8080): 0.0.0.0/0  # 블록체인 노드
  Custom (3000): 0.0.0.0/0  # 지갑 API
  ```

#### 2. 인스턴스 접속

```bash
# 키 파일 권한 설정
chmod 400 your-key.pem

# SSH 접속
ssh -i your-key.pem ubuntu@your-ec2-ip
```

#### 3. 서버 초기 설정

```bash
# 시스템 업데이트
sudo apt update && sudo apt upgrade -y

# 필수 도구 설치
sudo apt install -y git curl wget build-essential

# Docker 설치
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER
newgrp docker

# Docker Compose 설치
sudo curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
sudo chmod +x /usr/local/bin/docker-compose
```

#### 4. 프로젝트 배포

```bash
# 프로젝트 클론
cd /opt
sudo git clone https://github.com/your-org/BlockChain.git
sudo chown -R $USER:$USER BlockChain
cd BlockChain

# 환경 변수 설정
cp .env.example .env.production
nano .env.production  # 환경 변수 수정

# 빌드 및 실행
docker-compose -f docker-compose.prod.yml up -d --build

# 로그 확인
docker-compose logs -f
```

#### 5. 자동 시작 설정

```bash
# Systemd 서비스 생성
sudo nano /etc/systemd/system/konet-blockchain.service
```

내용:
```ini
[Unit]
Description=KONET Blockchain Service
Requires=docker.service
After=docker.service

[Service]
Type=oneshot
RemainAfterExit=yes
WorkingDirectory=/opt/BlockChain
ExecStart=/usr/local/bin/docker-compose -f docker-compose.prod.yml up -d
ExecStop=/usr/local/bin/docker-compose -f docker-compose.prod.yml down
TimeoutStartSec=0

[Install]
WantedBy=multi-user.target
```

```bash
# 서비스 활성화
sudo systemctl enable konet-blockchain
sudo systemctl start konet-blockchain
sudo systemctl status konet-blockchain
```

### B. ECS (Elastic Container Service)로 배포 (권장)

#### 1. ECR에 이미지 푸시

```bash
# AWS CLI 설치
pip3 install awscli

# AWS 설정
aws configure

# ECR 레지스트리 생성
aws ecr create-repository --repository-name konet-blockchain

# Docker 로그인
aws ecr get-login-password --region ap-northeast-2 | docker login --username AWS --password-stdin your-account-id.dkr.ecr.ap-northeast-2.amazonaws.com

# 이미지 빌드 및 태그
docker build -t konet-blockchain -f docker/Dockerfile.blockchain .
docker tag konet-blockchain:latest your-account-id.dkr.ecr.ap-northeast-2.amazonaws.com/konet-blockchain:latest

# 푸시
docker push your-account-id.dkr.ecr.ap-northeast-2.amazonaws.com/konet-blockchain:latest
```

#### 2. ECS 클러스터 생성

**AWS 콘솔 → ECS → 클러스터 생성**

- 클러스터 이름: `konet-cluster`
- 인프라: Fargate (서버리스)

#### 3. 태스크 정의 생성

**태스크 정의 → 새로 생성**

JSON 파일 (`ecs-task-definition.json`):
```json
{
  "family": "konet-blockchain",
  "networkMode": "awsvpc",
  "requiresCompatibilities": ["FARGATE"],
  "cpu": "1024",
  "memory": "2048",
  "containerDefinitions": [
    {
      "name": "blockchain-node",
      "image": "your-account-id.dkr.ecr.ap-northeast-2.amazonaws.com/konet-blockchain:latest",
      "portMappings": [
        {
          "containerPort": 8080,
          "protocol": "tcp"
        }
      ],
      "environment": [
        {
          "name": "RUST_LOG",
          "value": "info"
        }
      ],
      "logConfiguration": {
        "logDriver": "awslogs",
        "options": {
          "awslogs-group": "/ecs/konet-blockchain",
          "awslogs-region": "ap-northeast-2",
          "awslogs-stream-prefix": "ecs"
        }
      }
    }
  ]
}
```

```bash
# 태스크 정의 등록
aws ecs register-task-definition --cli-input-json file://ecs-task-definition.json
```

#### 4. 서비스 생성 및 실행

```bash
# 서비스 생성
aws ecs create-service \
  --cluster konet-cluster \
  --service-name konet-blockchain-service \
  --task-definition konet-blockchain \
  --desired-count 2 \
  --launch-type FARGATE \
  --network-configuration "awsvpcConfiguration={subnets=[subnet-xxx,subnet-yyy],securityGroups=[sg-xxx],assignPublicIp=ENABLED}"
```

## 🌐 GCP 배포

### A. Compute Engine으로 배포

#### 1. VM 인스턴스 생성

```bash
# gcloud CLI 설치 (로컬)
curl https://sdk.cloud.google.com | bash
exec -l $SHELL
gcloud init

# VM 생성
gcloud compute instances create konet-blockchain \
  --zone=asia-northeast3-a \
  --machine-type=e2-medium \
  --image-family=ubuntu-2404-lts-amd64 \
  --image-project=ubuntu-os-cloud \
  --boot-disk-size=100GB \
  --tags=http-server,https-server
```

#### 2. 방화벽 규칙 추가

```bash
# HTTP
gcloud compute firewall-rules create allow-http \
  --allow tcp:80 \
  --target-tags http-server

# HTTPS
gcloud compute firewall-rules create allow-https \
  --allow tcp:443 \
  --target-tags https-server

# 블록체인 노드
gcloud compute firewall-rules create allow-blockchain \
  --allow tcp:8080 \
  --target-tags http-server
```

#### 3. SSH 접속 및 배포

```bash
# SSH 접속
gcloud compute ssh konet-blockchain --zone=asia-northeast3-a

# 이후 과정은 AWS EC2와 동일
```

### B. Cloud Run으로 배포 (서버리스)

#### 1. 컨테이너 이미지 빌드

```bash
# Cloud Build 사용
gcloud builds submit --tag gcr.io/your-project-id/konet-blockchain
```

```bash

  --platform managed \
  --region asia-northeast3 \
  --allow-unauthenticated \
  --port 8080 \
  --memory 2Gi \
  --cpu 1 \
  --max-instances 10
```

## 🐳 Docker 배포 (모든 플랫폼)

### docker-compose.prod.yml

```yaml
version: '3.8'

services:
  blockchain-node:
    image: your-registry/konet-blockchain:latest
    restart: always
    ports:
      - "8080:8080"
    environment:
      - RUST_LOG=info
    volumes:
      - /data/blockchain:/app/data
    logging:
      driver: "json-file"
      options:
        max-size: "10m"
        max-file: "3"

  # ... 다른 서비스들
```

### 배포 명령어

```bash
# 프로덕션 모드 실행
docker-compose -f docker-compose.prod.yml up -d

# 업데이트 배포
docker-compose -f docker-compose.prod.yml pull
docker-compose -f docker-compose.prod.yml up -d --force-recreate

# 로그 확인
docker-compose -f docker-compose.prod.yml logs -f --tail=100
```

## ☸️ Kubernetes 배포

### 1. Deployment 생성

`k8s/deployment.yaml`:
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: konet-blockchain
  namespace: konet
spec:
  replicas: 3
  selector:
    matchLabels:
      app: konet-blockchain
  template:
    metadata:
      labels:
        app: konet-blockchain
    spec:
      containers:
      - name: blockchain-node
        image: your-registry/konet-blockchain:latest
        ports:
        - containerPort: 8080
        env:
        - name: RUST_LOG
          value: "info"
        resources:
          requests:
            memory: "1Gi"
            cpu: "500m"
          limits:
            memory: "2Gi"
            cpu: "1000m"
        livenessProbe:
          httpGet:
            path: /
            port: 8080
          initialDelaySeconds: 30
          periodSeconds: 10
        readinessProbe:
          httpGet:
            path: /
            port: 8080
          initialDelaySeconds: 10
          periodSeconds: 5
```

### 2. Service 생성

`k8s/service.yaml`:
```yaml
apiVersion: v1
kind: Service
metadata:
  name: konet-blockchain-service
  namespace: konet
spec:
  type: LoadBalancer
  selector:
    app: konet-blockchain
  ports:
  - protocol: TCP
    port: 80
    targetPort: 8080
```

### 3. 배포

```bash
# 네임스페이스 생성
kubectl create namespace konet

# 배포
kubectl apply -f k8s/deployment.yaml
kubectl apply -f k8s/service.yaml

# 상태 확인
kubectl get pods -n konet
kubectl get svc -n konet

# 로그 확인
kubectl logs -f deployment/konet-blockchain -n konet
```

## 🌐 도메인 및 SSL 설정

### A. 도메인 연결

#### AWS Route 53
```bash
# 호스팅 영역 생성
aws route53 create-hosted-zone --name konet.io --caller-reference 2024-01-01

# A 레코드 추가 (ELB 또는 EC2 IP)
aws route53 change-resource-record-sets --hosted-zone-id Z1234567890ABC --change-batch file://dns-record.json
```

#### Cloudflare
1. Cloudflare 대시보드 접속
2. 도메인 추가
3. A 레코드 추가: `api.konet.io` → `your-server-ip`
4. CNAME 추가: `www.konet.io` → `konet.io`

### B. SSL 인증서 (Let's Encrypt)

#### Certbot 사용

```bash
# Certbot 설치
sudo apt install certbot python3-certbot-nginx

# 인증서 발급
sudo certbot --nginx -d konet.io -d www.konet.io

# 자동 갱신 설정
sudo certbot renew --dry-run

# Cron job 추가
sudo crontab -e
# 매일 오전 2시에 갱신 시도
0 2 * * * certbot renew --quiet
```

## 🔄 업데이트 배포

### 제로 다운타임 배포

#### 1. 새 버전 빌드

```bash
# 버전 태그
git tag v1.1.0
git push origin v1.1.0

# 이미지 빌드
docker build -t konet-blockchain:v1.1.0 .
docker tag konet-blockchain:v1.1.0 your-registry/konet-blockchain:v1.1.0
docker push your-registry/konet-blockchain:v1.1.0
```

#### 2. Rolling Update (Kubernetes)

```bash
# 이미지 업데이트
kubectl set image deployment/konet-blockchain \
  blockchain-node=your-registry/konet-blockchain:v1.1.0 \
  -n konet

# 롤아웃 상태 확인
kubectl rollout status deployment/konet-blockchain -n konet

# 롤백 (문제 발생 시)
kubectl rollout undo deployment/konet-blockchain -n konet
```

## 🆘 문제 해결

### 컨테이너가 시작되지 않음

```bash
# 로그 확인
docker logs <container-id>

# 컨테이너 안으로 들어가기
docker exec -it <container-id> /bin/bash
```

### 메모리 부족

```bash
# 메모리 사용량 확인
docker stats

# 스왑 메모리 추가 (EC2)
sudo fallocate -l 4G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
```
