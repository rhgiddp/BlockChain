## 🚀 로컬 블록체인 네트워크 실행

### 방법 1: Docker Compose (추천!)

**장점:**
- 한 번에 모든 서비스 실행
- 환경 격리
- 설정 간편

```bash
# 프로젝트 루트에서
docker-compose up -d

# 로그 확인
docker-compose logs -f

# 특정 서비스만 로그 보기

# 상태 확인
docker-compose ps

# 중지
docker-compose down

# 완전히 삭제 (데이터 포함)
docker-compose down -v
```

**실행되는 서비스들:**
- `blockchain-node`: 블록체인 노드
- `postgres`: 데이터베이스

**7. 배포 스크립트 예시**

`scripts/deploy.js`:
```javascript
const hre = require("hardhat");

async function main() {
  // 컨트랙트 가져오기
  const Token = await hre.ethers.getContractFactory("Token");

  // 배포
  console.log("Deploying Token...");
  const token = await Token.deploy("KONET", "KON", 1000000);

  await token.deployed();

  console.log("Token deployed to:", token.address);

  // 검증 (etherscan 등)
  if (network.name !== "localhost") {
    console.log("Waiting for block confirmations...");
    await token.deployTransaction.wait(6);

    await hre.run("verify:verify", {
      address: token.address,
      constructorArguments: ["KONET", "KON", 1000000],
    });
  }
}

main().catch((error) => {
  console.error(error);
  process.exitCode = 1;
});
```

**8. 테스트 예시**

`test/Token.test.js`:
```javascript
const { expect } = require("chai");
const { ethers } = require("hardhat");

describe("Token", function () {
  let token;
  let owner;
  let addr1;

  beforeEach(async function () {
    const Token = await ethers.getContractFactory("Token");
    [owner, addr1] = await ethers.getSigners();
    token = await Token.deploy("KONET", "KON", 1000000);
    await token.deployed();
  });

  it("Should have correct name and symbol", async function () {
    expect(await token.name()).to.equal("KONET");
    expect(await token.symbol()).to.equal("KON");
  });

  it("Should transfer tokens", async function () {
    await token.transfer(addr1.address, 100);
    expect(await token.balanceOf(addr1.address)).to.equal(100);
  });
});
```

## 🆘 문제 해결

### 자주 발생하는 문제

#### 1. Rust 컴파일 에러: "linker `cc` not found"

**해결:**
```bash
# Ubuntu/WSL2
sudo apt install build-essential

# Mac
xcode-select --install
```

---

#### 2. npm ERR! EACCES: permission denied

**해결:**
```bash
# 전역 npm 디렉토리 변경
mkdir ~/.npm-global
npm config set prefix '~/.npm-global'
echo 'export PATH=~/.npm-global/bin:$PATH' >> ~/.bashrc
source ~/.bashrc
```

---

#### 3. Hardhat Error: "Cannot find module '@nomicfoundation/hardhat-toolbox'"

**해결:**
```bash
cd smart-contracts
rm -rf node_modules package-lock.json
npm install
```

---

#### 4. Docker "port already allocated"

**해결:**
```bash
# 포트 사용 프로세스 찾기
lsof -i :8545

# 프로세스 종료
kill -9 <PID>

# 또는 docker-compose 포트 변경
# docker-compose.yml에서 "8545:8545" → "8546:8545"
```

---

#### 5. Rust "out of memory" 에러

**해결:**
```bash
# 병렬 빌드 수 제한
cargo build -j 2

# 또는 환경 변수 설정
export CARGO_BUILD_JOBS=2
```
