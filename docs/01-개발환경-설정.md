## 🖥️ 운영체제별 준비사항

### Windows 사용자

#### WSL2 (Windows Subsystem for Linux) 설치 필수!

블록체인 개발은 Linux 환경에서 가장 잘 작동합니다.

**1. PowerShell을 관리자로 실행**
```powershell
# Windows 키를 누르고 "PowerShell" 검색
# 오른쪽 클릭 → "관리자로 실행"

# WSL 설치 명령
wsl --install
```

**2. 컴퓨터 재시작**

**3. Ubuntu 자동 설치 확인**
```powershell
wsl --list --verbose
```

출력 예시:
```
  NAME            STATE           VERSION
* Ubuntu          Running         2
```

**4. Ubuntu 실행**
```powershell
wsl
```

이제 Ubuntu Linux 터미널에 들어왔습니다!

## 🦀 개발 언어 설치

### 1. Rust (블록체인 코어 개발)

**왜 필요한가요?**
- 블록체인 메인넷 개발
- 거래소 엔진 개발
- 고성능 모듈 개발

#### 설치 (모든 OS 공통)

```bash
# Rust 공식 설치 스크립트
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

**설치 중 선택:**
```
1) Proceed with installation (default)
2) Customize installation
3) Cancel installation

→ 1 입력 후 Enter
```

#### 환경 변수 설정
```bash
source $HOME/.cargo/env
```

#### 확인
```bash
rustc --version
cargo --version
```

출력 예시:
```
rustc 1.80.0 (2024 edition)
cargo 1.80.0
```

#### Rust 도구 추가 설치
```bash
# 코드 포맷터
rustup component add rustfmt

# 린터 (코드 검사)
rustup component add clippy

# WebAssembly 타겟 (스마트 컨트랙트용)
rustup target add wasm32-unknown-unknown
```

# 최신 LTS 버전 설치

nvm alias default node

## 🐳 Docker 및 Kubernetes

### Docker (컨테이너 플랫폼)

**무엇인가요?**
애플리케이션을 컨테이너로 패키징하여 어디서나 동일하게 실행합니다.

#### Windows

**1. Docker Desktop 설치**
1. https://www.docker.com/products/docker-desktop 방문
2. "Download for Windows" 클릭
3. 설치 후 재시작

**2. WSL2 통합 활성화**
- Docker Desktop 실행
- Settings → Resources → WSL Integration
- Ubuntu 체크
- Apply & Restart

#### Mac

```bash
brew install --cask docker
```

또는 https://www.docker.com/products/docker-desktop 에서 다운로드

#### Linux

**Ubuntu:**
```bash
# Docker 공식 GPG 키 추가
sudo apt update
sudo apt install ca-certificates curl gnupg -y
sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
sudo chmod a+r /etc/apt/keyrings/docker.gpg

# Docker 저장소 추가
echo \
  "deb [arch="$(dpkg --print-architecture)" signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu \
  "$(. /etc/os-release && echo "$VERSION_CODENAME")" stable" | \
  sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

# Docker 설치
sudo apt update
sudo apt install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin -y

# 현재 사용자를 docker 그룹에 추가 (sudo 없이 사용)
sudo usermod -aG docker $USER
newgrp docker
```

#### 확인
```bash
docker --version
docker compose version

# 테스트 실행
docker run hello-world
```

출력에 "Hello from Docker!"가 나오면 성공!

## ✅ 설치 확인

모든 도구가 제대로 설치되었는지 한 번에 확인하는 스크립트입니다.

### 확인 스크립트 생성

```bash
# 홈 디렉토리에 스크립트 생성
cat > ~/check-install.sh << 'EOF'
#!/bin/bash

echo "🔍 개발 환경 설치 확인 중..."
echo ""

# 색상 정의
GREEN='\033[0;32m'
RED='\033[0;31m'
NC='\033[0m' # No Color

check_command() {
    if command -v $1 &> /dev/null; then
        echo -e "${GREEN}✓${NC} $1: $($1 --version 2>&1 | head -n 1)"
    else
        echo -e "${RED}✗${NC} $1: 설치되지 않음"
    fi
}

echo "📦 필수 도구:"
check_command git
check_command curl
check_command wget
check_command gcc
check_command make

echo ""
echo "🦀 Rust:"
check_command rustc
check_command cargo

echo ""
echo "📦 Node.js:"
check_command node
check_command npm

echo ""
echo "🐍 Python:"
check_command python3
check_command pip3

echo ""
echo "🐳 Docker:"
check_command docker

echo ""
echo "🔧 블록체인 도구:"
check_command forge
check_command cast

echo ""
echo "✅ 확인 완료!"
EOF

# 실행 권한 부여
chmod +x ~/check-install.sh

# 실행
~/check-install.sh
```

## 🆘 문제 해결

### 일반적인 문제

#### 1. "command not found" 에러

**원인:** 환경 변수 PATH가 설정되지 않음

**해결:**
```bash
# ~/.bashrc 또는 ~/.zshrc 파일 수정
nano ~/.bashrc

# 파일 끝에 추가
export PATH="$HOME/.cargo/bin:$PATH"
export PATH="/usr/local/go/bin:$PATH"

# 저장 후 적용
source ~/.bashrc
```

---

#### 2. Rust 설치 후 "rustc: command not found"

**해결:**
```bash
# 환경 변수 다시 로드
source $HOME/.cargo/env

# 터미널 재시작
exec bash
```

---

#### 3. npm 권한 오류 (EACCES)

**증상:** `npm install -g` 할 때 권한 오류

**해결:**
```bash
# npm 전역 디렉토리 변경
mkdir ~/.npm-global
npm config set prefix '~/.npm-global'

# PATH 추가
echo 'export PATH=~/.npm-global/bin:$PATH' >> ~/.bashrc
source ~/.bashrc
```

---

#### 4. Docker "permission denied" 오류

**해결:**
```bash
# 현재 사용자를 docker 그룹에 추가
sudo usermod -aG docker $USER

# 로그아웃 후 다시 로그인하거나
newgrp docker

# Docker 서비스 재시작
sudo systemctl restart docker
```

---

#### 5. WSL2에서 인터넷 연결 안 됨

**해결:**
```bash
# Windows PowerShell에서 (관리자 권한)
wsl --shutdown

# 네트워크 초기화
netsh winsock reset

# 컴퓨터 재시작
```

---

#### 6. Mac M1/M2 (Apple Silicon) 호환성 문제

**해결:**
```bash
# Rosetta 2 설치 (Intel 앱 실행용)
softwareupdate --install-rosetta

# Homebrew ARM 버전 사용 확인
arch
# 출력: arm64

# 일부 도구는 x86_64 버전 필요 시
arch -x86_64 brew install <package>
```
